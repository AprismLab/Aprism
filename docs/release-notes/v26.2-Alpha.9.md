# Aprism Loader v26.2-Alpha.9 (Release Candidate)

The release candidate of the v26.2 minor line. Targets Minecraft Java
Edition 26.2. This build freezes the v26.2 API surface; the v26.2 official
release collapses Alpha.1 through Alpha.9.

## Contents

- `Aprism-v26.2-Alpha.9-JE-26.2.jar` — the self-contained javaagent (fat
  jar, dependencies relocated)
- `checksums.txt` — SHA-256 of the artifact
- `.sig` / `.bundle` — cosign keyless signatures
- `Aprism-sbom.cdx.json` — CycloneDX software bill of materials
