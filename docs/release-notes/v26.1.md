# Aprism Loader v26.1 (Official Release)

The official release of the v26.1 minor line of the 2026 major line.
Targets Minecraft Java Edition 26.2. This minor collapses Alpha.1 through
Alpha.9 into a single frozen, verified API surface.

## Highlights

- **Bedrock Edition injection foundation (Alpha.1-5)** — the complete
  Java-side BE injection runtime: fail-closed version database, injection
  plan computation, signature database persistence (JSON schema v1),
  injection coordinator wired into `AprismRuntime`, native attachment
  foundation (`NativeInjector` SPI + `BedrockNativeStager`), and the
  version adapter enforcing the 26.x-and-later scope boundary.
- **Loader-support extraction seam (Alpha.6, goal #4)** —
  `LoaderEntrypointHandler` SPI + registry so foreign-loader bridges
  (Fabric/Forge/NeoForge/Quilt/LiteLoader) can live outside
  aprism-loader-core, in the AprismRefract companion repository.
- **JE version-line foundation (Alpha.7, goal #1)** —
  `VersionLineRegistry` covering the supported JE line 1.20 .. 26.2 with
  per-version obfuscation profile (REMAPPED / NO_REMAP), Java baseline
  (17 / 21 / 25) and mappings source resolution.
- **Lower-level API (Alpha.8, goal #2, MCJEBooster layer)** —
  `ClassRedefiner` (runtime class redefinition/retransformation on
  `Instrumentation`), `MethodHookRegistry` (programmatic method hooks) and
  `MethodHookTransformer` (ASM pass injecting hook dispatch at method
  entry, wired as the fourth transformation pass).
- **Stronger AEP capabilities (Alpha.9, goal #3)** — extension `priority`
  ordering, `depends` validation against the full capability set, and
  `IAprismExtension.onPostInitialize` / `onShutdown` lifecycle hooks.

## Quick start

```
java -javaagent:Aprism-v26.1-JE-26.2.jar=aprismVersion=v26.1;mcEdit=JE;mcVersion=26.2;gameRoot=<path-to-game-dir> ...
```

Place `.aje` mods in `<game-dir>/mods/`; loader-support extensions
(`.aep`, e.g. Fabric-Support / NeoForge-Support from the AprismRefract
releases) go into `<game-dir>/aprism-extensions/`. See
docs/zh/08-开发者指南.md and docs/en/08-developer-guide.md.

## Known issues

- BE native platform injector implementations (Windows proxy-DLL, Android
  Zygisk/container, iOS) are not yet part of the release; this minor
  delivers the complete Java-side foundation (version DB, injection plan,
  coordinator, adapter, native staging). Real-game BE smoke requires a
  Minecraft Bedrock installation.
- Foreign-loader bridges still ship inside aprism-loader-core as
  transitional fallbacks while AprismRefract branches (fabric / forge /
  neoforge / quilt / liteloader) complete the migration through the
  Alpha.6 extraction seam.
- Extension `depends` validation checks dependency presence against the
  capability set; SemVer range matching of dependency versions is deferred.
- Real-game harness coverage is JE 26.2 via MDL; 26.1.2 and legacy lines
  rely on the version-line registry profiles without live-game runs yet.
