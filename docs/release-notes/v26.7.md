# v26.7 Release Notes

> Aprism Loader v26.7 — Content superset landing
> Author: BlockConnect@StarsailsClover

## Overview

The v26.7 line turns the v26.5/v26.6 registration contracts into REAL game
capabilities, proven live inside a running Minecraft 26.2 world with dual
agents (Aprism + Despotes) coexisting. The QA2 verdict — "contract superset,
not capability superset" — is now closed: Aprism-native mods can add real
items and working commands to the live game.

## Alpha line

### Alpha.1 — Real content registration (SMOKE PASS)

`GameContentBindingInstaller` reflects ItemContent/BlockContent from
GameRegistries into the live BuiltInRegistries via the static
Registry.register helper (NO_REMAP profile; fail-closed elsewhere).
Live proof: aprism:smoke_ruby bound in a running Minecraft 26.2.

### Alpha.2 — Command dispatcher binding layer

`BrigadierCommandBinder`: frozen CommandSpecs reflected into a live
CommandDispatcher via LiteralArgumentBuilder + register(); untyped handlers
adapted through a dynamic proxy onto Brigadier's Command interface.
Fail-closed NO_DISPATCHER until the discovery seam lands (it did - Alpha.5).

### Alpha.3 — Key-binding input mapping

`KeyInputBindingInstaller`: KeyBindingSpecs become net.minecraft.client
KeyMapping instances (Category.MISC record, GLFW keycode) appended to
Options.keyMappings via accessible-final array swap; auto-discovers the
client through Minecraft.getInstance().

### Alpha.4 — Network stack adapter

`NetworkStackAdapter` constructs CustomPacketPayload instances for Aprism
channels (createType factory / Type record over Identifier); payload bytes
ride FriendlyByteBuf at the transport seam. Fail-closed on reflection misses.

### Alpha.5 — Live per-world instance discovery seam

`LiveInstanceDiscovery`: one reflective seam for the per-world instances
every binder needed (client singleton, ClientPacketListener.send,
ServerboundCustomPayloadPacket, integrated-server dispatcher chain).
`BrigadierCommandBinder.bindWhenAvailable(30 min)` polls until world join.
Fabric-host support: `isFabricHost()` defers Mixin ownership to Knot;
`-PfabricVariant=true` build mode relocates ASM and drops our Mixin classes.

**LIVE-FIRE PROOF**: in one running world with dual agents -
"Live command dispatcher discovered (integrated server)" +
"Command binding: 1/1 bound" + /aprism_hello executed with zero
Unknown-command rejections + APRISM-MIXIN-PROOF woven into
net.minecraft.client.Minecraft.

### Alpha.6 — Settings access surface

api `SettingsAccess` + loader impl: per-mod typed get/set validated against
manifest declarations, typed getters, schema() rendering for GUI renderers,
fail-safe change listeners. Wired via AprismContext.getSettings().

### Alpha.7 — DEC-PRE261: pre-26.1 binding strategy

Binders require NO_REMAP (26.1+). REMAPPED profiles refuse fail-closed with
an actionable hint. Cross-mapping via Mojang official mappings promoted to a
named v26.8 candidate workstream; 26.x-first priority maintained.

### Alpha.8 — Multi-content soak (live)

examplemod registered 10 soak items + 5 blocks + 2 commands; the live world
bound ALL items (11/11) and BOTH commands (2/2); /aprism_soak executed
in-game with zero Unknown-command rejections. Block binding needs a provider
seam (BlockBehaviour.Properties factory requires HolderLookup) - refinement
scheduled. Startup baseline refreshed.
