# v26.8 发布说明

> Aprism Loader v26.8 - 基于跨映射链的真实 pre-26.1 内容绑定
> 作者：BlockConnect@StarsailsClover

## 概述

v26.8 线完成 DEC-PRE261 方案 A：Aprism 原生内容现在通过 Mojang 官方映射
跨解析链（官方名 -> 运行时名，覆盖类、字段、方法，以及 Alpha.9 起
重载精确的方法签名）绑定进 26.1 之前真实混淆的 Minecraft 版本。
本线同时交付 AEP 编辑器能力目录与 BC 项目管理合规整改。

## Alpha 线

### Alpha.1 - OfficialMappings 基础
Mojang client.txt 解析器（类/静态字段/方法），并发现方向反转：Mojang
client.txt 行为 official -> obfuscated，与标准 ProGuard 相反。
fail-closed 的 REMAPPED 门接入内容绑定器。

### Alpha.2 - 字段级跨映射
静态字段翻译（BuiltInRegistries.ITEM/BLOCK），使注册表句柄在混淆
运行时上可解析。

### Alpha.3 - 映射感知引导门
GameBootstrapGate.setProbeNames 经已加载映射翻译原版引导探针
（1.21.4：akx/a），延迟 mod 生命周期分发在混淆 profile 上正确生效。

### Alpha.4 - Identifier 工厂翻译
parse 工厂经映射解析（1.21.4：akv.a），保留 26.x Identifier 到
pre-26.1 ResourceLocation 的回退。

### Alpha.5 - ResourceKey 与 setId 链
Registries.ITEM/BLOCK（ResourceKey 常量）、ResourceKey.create、
Properties#setId(ResourceKey) 全部经映射解析（1.21.4：mc.K、a、b/a），
打通现代 MC 物品构造（"Item id not set"）。

### Alpha.6 - 签名精确的重载消歧
OfficialMappings 增加参数签名表；runtimeMethodName(class, method,
paramTypes) 消歧同名重载（containsKey(RL)->d 与 containsKey(RK)->e），
保留名字表回退。

### Alpha.7 - 堆叠上限应用实机证明
stacksTo(int)/maxCount(int)/maxStackSize(int) 以 int 参数类型探测。
实机证据：声明 maxStack 16，从活体物品读回
"maxStackSize readback: 'aprism:realsmoke_item' = 16"。

### Alpha.8 - 方块属性应用
strength(float,float) 与 lightLevel(ToIntFunction)（反射 Proxy）以
fail-open 方式应用。实机证据：从活体方块读回
destroyTime=3.0 explosionResistance=6.0，与声明完全一致。

### Alpha.9 - Minecraft 1.21.4 端到端实机证明
真实混淆 Minecraft 1.21.4（JDK 25），harness 位于
smoke-harness/1.21.4/：

- Content binding: 2/2 unit(s) bound to the live registries
- Registry readback: 'aprism:realsmoke_item' present in the live item registry
- Registry readback: 'aprism:realsmoke_block' present in the live block registry
- maxStackSize readback: 'aprism:realsmoke_item' = 16
- block property readback: 'aprism:realsmoke_block' destroyTime=3.0 explosionResistance=6.0
- 原版资产管线独立处理了已绑定方块
  （Missing model for variant: 'aprism:realsmoke_block#'）
- 真实 1.21.4 客户端在 agent 下进入世界（Player407 joined the game）
