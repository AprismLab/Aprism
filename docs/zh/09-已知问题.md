# Aprism Loader v26.2 — 已知问题

> v26.2 官方版的配套文档。维护者：BlockConnect@StarsailsClover。条目按主题排列，不按严重度；均为随 v26.2 GA 明确知悉而发布的事项。

## JE 加载器核心

1. **无游戏事件分发。** `CLIENT` 与 `SERVER` 生命周期阶段已声明且可分发，但尚无真实游戏事件钩子：这些阶段仅在启动器显式提供分发侧（`side=client|server` agent 参数）时触发。钩住真实游戏事件（tick、渲染、网络）是后续里程碑。
2. **注册表仅有泛型能力。** `AprismRegistry` 与 `registry/` 子包暴露泛型注册表 API。绑定到真实 Minecraft 游戏注册表的类型化 Block/Item/Entity 注册表尚不存在。
3. **无网络 API。** JE 生态的包（packet）API 均无 Aprism 等价物。需要自定义数据包的模组必须使用 Mixin。
4. **入口点发现仅依赖清单。** Aprism 原生路径上没有针对 Forge 风格 `@Mod` 发现的注解扫描回退；Forge/NeoForge 模组经由各自的 loader-support 扩展运行，由扩展自行扫描 `@Mod` 注解。

## Loader 支持（目标 #4，已于 v26.2-Alpha.5 关闭）

5. **外部分发仅走 SPI。** 自 v26.2-Alpha.5 起，核心不再携带内置外部 loader 桥接。外部 loader 模组目录仅在其 `.aep` loader-support 扩展已安装时被扫描，其模组仅在扩展的 `LoaderEntrypointHandler` 已注册时被分发。没有注册处理器的外部模组会被发现但永不执行。
6. **扩展依赖区间仅做存在性校验。** 扩展间的 `depends` 校验被引用的 id/能力是否存在；依赖版本的 SemVer 区间匹配推迟处理。

## 基岩版（Bedrock Edition）

7. **目前仅 Java 侧。** v26.1 交付了完整的 Java 侧 BE 基础（版本库、注入计划、协调器、原生安置、版本适配器）。原生平台注入器（Windows 代理 DLL、Android Zygisk/容器、iOS）尚未实现；详见 BE 方案研究报告（`docs/research/bedrock-approach/`）。
8. **无真实游戏 BE 冒烟。** 本机未安装 Minecraft 基岩版，BE 行为仅由单元/集成测试验证。
9. **封禁风险。** 在启用 Xbox Live 的存档上进行 BE 原生修改存在真实的封禁风险。请使用离线存档。已在 Doc 01 §13.2 披露。

## 真实游戏验证

10. **Harness 覆盖仅 JE 26.2。** MDL 驱动的真实游戏冒烟针对 Minecraft 26.2（JDK 25）运行。26.1.2 与旧版本线（1.16.5 / 1.21.x）由版本线注册表配置与单元测试覆盖，无真机运行。
11. **MDL 无 `-javaagent` 配置键。** Harness 直接用 agent 启动游戏；MDL 用于实例/日志/游戏控制。更深入的 MDL 集成已在计划中。

## 分发

12. **仅独立下载。** Aprism 不上架 Microsoft Store 与 Apple App Store（两者均禁止商店分发应用中的动态代码注入）。
13. **Modrinth 镜像尚未发布。** v26.2 GA 时 GitHub Releases 是唯一产物渠道。
