# v26.6 Release Notes

> Aprism Loader v26.6 — Production readiness + user surface
> Author: BlockConnect@StarsailsClover

## Overview

The v26.6 line builds the user-facing surface on top of the v26.5 game-side
installers: a guided installer, machine-readable runtime status for launcher
tooling, Modrinth mirror distribution, and the aprism-report support bundle.
Every Alpha ships green tests; the line includes a real-game SMOKE PASS.

## Alpha line

### Alpha.1 — User installer + launch profile generation

`com.aprism.loader.installer`: LauncherType detection (Prism, ATLauncher,
GDLauncher, Generic), immutable LaunchProfile with javaagentArg() rendering,
per-launcher config generation (Prism instance.cfg PreLaunchCommand,
ATLauncher/GDLauncher JSON, Generic .bat/.sh scripts), InstallationValidator
with fail-closed checks and warnings, and an end-user FirstRunReport.
28 tests.

### Alpha.2 — MDL deep integration: machine-readable status

`StatusPublisher` writes `<gameRoot>/aprism-status.json`
(schema `aprism.status/v1`) after every load milestone: phase,
ok/failure counts, per-unit entries with durations. Atomic publish,
fail-safe IO. Verified end-to-end inside a real Minecraft process.
MDL diagnose (and any tool) now queries one file instead of parsing logs.
10 tests.

### Alpha.3 — Modrinth mirror distribution (known-issue #13 closed)

`DistributionResolver` computes canonical artifact names, deterministic
GitHub tag-download URLs, primary-channel checksums, and a stable describe()
map. The release workflow mirrors every signed jar to Modrinth via the v2
API (gated on MODRINTH_TOKEN so forks run green). GitHub Releases remains
the verification-authoritative channel. 7 tests.

### Alpha.4 — Support report (aprism-report)

`SupportReportBuilder` assembles `<gameRoot>/aprism-report.txt`: environment
identity, LoadReport summary, per-failure details with actionable hints
(6 mapped failure signatures), agent-vs-prismate mutual-exclusion warning,
last-100 structured-log tail, mod list snapshot. Fail-safe contract. 9 tests.

### Alpha.5–7 — BE native injector (reserved)

Per the owner's decision, Aprism BE work stays frozen until the September
reverse-engineering milestone begins. These alphas remain reserved for the
BE line: Windows P0 proxy-DLL injector, signature DB field population, and
end-to-end .abe loading.

### Alpha.8 — Real-game smoke + status proof

SMOKE PASS against real Minecraft 26.2 / JDK 25: examplemod + mixinproof
reached the full lifecycle, Load Report emitted with 0 failures, and
aprism-status.json was written by the live game (phase LOADED, okCount 2).
This is the v26.6 line's Doc 10 §5.3 smoke pass.

### Alpha.9 — Release candidate freeze

Full suite re-verified; API surface frozen for GA.
