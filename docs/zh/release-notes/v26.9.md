# v26.9 Release Notes

> Aprism Loader v26.9 — AEP 编辑器能力目录 + 扩展版本元数据
> 作者：BlockConnect@StarsailsClover
> 状态：草稿（基于 v26.8-Alpha.8 路径，v26.9 GA 前可能修订）

## 概述

v26.9 线把 AprismWarp 的只读 Node 端能力索引，落地为一个向后兼容、声明式的 AEP 元数据字段。运行时 AEP 契约不变：编辑器目录是可选的，Aprism 运行时忽略它，v26.9 之前产出的任何 AEP 不带它也仍然可安装。新元数据今天已随 AEP 格式适配发布出现在所有 Refract 分支（`fabric|neoforge|forge|quilt|liteloader/v26.9-Alpha.2`）。

## Alpha 线

### Alpha.1 — AprismWarp 目录接入（存在于 Aprism v26.8-Alpha.8）

- 打包插件接受根级可选的 `aprismwarp.editor.json`，schema 为
  `aprismwarp.aep-editor/v1`。该目录只是声明：Aprism 运行时忽略，
  AprismWarp 在不加载扩展 jar 的前提下读取它。
- 扩展清单新增可选 `version`（SemVer）字段，由 Aprism 运行时用于
  扩展依赖范围匹配。缺省保留 v26.8 行为。
- `AprismPackagingExtension` 暴露 `editorManifestFile`，由
  `AprismPackagingPlugin` 透传到每个 `packageAep` 任务。旧版无该目录
  的 AEP 仍然可安装。
- `PackageAepTaskTest` 覆盖：根 `aprism.extension.json` 存在、根
  `aprismwarp.editor.json` 存在、内嵌扩展 jar 存在。

### Alpha.2 — Refract 适配（v26.9-Alpha.2）

所有五个 Refract 分支在每个变体里都附带编辑器目录，并声明扩展自身版本。
上游 SDK 文档已补充目录规则与 Gradle DSL 配置
（`aprismPackaging.editorManifestFile`）。

- 32/32 个 AEP 变体通过结构校验（根清单 + 根编辑器目录 + 一个内嵌 jar）。
- 五次 workflow_dispatch 全部成功，发布 5 个 Pre-Release，附带 cosign
  keyless 签名与 CycloneDX SBOM。

## 验证

- Aprism TestKit：`PackageAepTaskTest` 通过。
- AprismWarp：只读 Node 端 ZIP 检查器演练新协议。
- AprismRefract：通过 JDK `jar tf` 完成 32/32 结构校验；五次 dispatch
  运行全部成功；一份下载的 `Fabric-Support-...-26.2.aep` 含预期三
  个根条目。
