# v26.5 Release Notes

> Aprism Loader v26.5 — Game-side landing + real driving
> Author: BlockConnect@StarsailsClover

## Overview

The v26.5 line closes the remaining QA0 gaps and turns registration-only
parity surfaces into actually-driven, game-connected capabilities. Every
Alpha ships green tests, signed commits, and cosign-verified Pre-Releases.

## Alpha line

### Alpha.1 — Annotation-scan entrypoint discovery (QA0 gap #5 closed)

`@AprismMod` annotation scanning for Aprism-native mods when the manifest
does not declare explicit entrypoints. ASM-based scanner, no class loading.

### Alpha.2 — Extension dependency SemVer range matching (known-issue #6 closed)

`AprismExtensionManifest.version` field added; `extensionDependenciesSatisfied`
now uses full `VersionRange` for SemVer range matching instead of
presence-only checks.

### Alpha.3 — Game-event real dispatch

`GameEventHookInstaller` bridges MC's tick/render/world methods through the
`MethodHookRegistry` into the `GameEventDispatcher`. Platform adapter layer
supplies version-specific hook targets.

### Alpha.4 — Command binding installer

`CommandBindingInstaller` + `CommandDispatcherBridge` bridge registered
commands to the MC command dispatcher. Fail-safe per-command binding.

### Alpha.5 — Key-binding binding installer

`KeyBindingBindingInstaller` + `InputSystemBridge` bridge registered key
bindings to the MC input system. Fail-safe per-binding.

### Alpha.6 — Tick scheduler driver

`TickSchedulerDriver` registers as a `GameTickEvent` listener and drives
`TickScheduler.runTick()` on the active side (CLIENT or SERVER).

### Alpha.7 — Resource reload trigger

`ResourceReloadTrigger` uses method hooks to detect MC resource-manager
reload events and fires `ResourceReloadRegistry.fireReload()`.

### Alpha.8 — Network transport installer

`NetworkTransportInstaller` bridges the MC network stack into the
`NetworkingRegistry`: attaches outbound transport, delivers inbound packets.

### Alpha.9 — Release candidate

Full test suite re-verified: 670 tests, 0 failures, 5 skipped.
API surface frozen for GA.
